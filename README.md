
# Portfolio Website 

This is my personal portfolio website built with **Next.js**, **TailwindCSS**, and modern UI components.  
It showcases my skills, projects, education, and experience.

##  Features
- Responsive design
- Animated transitions
- Skills & projects showcase
- Contact form integration

##  Tech Stack
- Next.js
- React
- TailwindCSS
- shadcn/ui
- Lucide icons

##  Installation
```bash
git clone https://github.com/farhan0496/portfolio.git
cd portfolio
npm install
npm run dev
